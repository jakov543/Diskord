Diskord sound files
===================

The .ogg files in this folder are Android sounds made by Google for the
Android Open Source Project (platform/frameworks/base, data/sounds):

  message.ogg   <- notifications/material/ogg/Tethys.ogg
  mention.ogg   <- notifications/material/ogg/Io.ogg
  friend.ogg    <- notifications/material/ogg/Ariel.ogg
  ring.ogg      <- ringtones/material/ogg/Titania.ogg (shortened, fade out, mono)
  join.ogg      <- effects/ogg/VideoRecord.ogg (made louder)
  leave.ogg     <- effects/ogg/VideoStop.ogg (made louder)
  mute.ogg      <- effects/ogg/Lock.ogg (made louder)
  unmute.ogg    <- effects/ogg/Unlock.ogg (made louder)
  deafen.ogg    <- effects/ogg/Undock.ogg
  undeafen.ogg  <- effects/ogg/Dock.ogg (made louder)
